🚀 三步驟立刻開玩

  1. 老師統一開房：老師點擊首頁的「👩‍🏫 我是老師：前往統一開房」設定房號、小隊名稱與遊戲模式（也能一鍵批次開多隊）。
  2. 學生兩步加入：所有學生畫面統一！先輸入「房號 + 暱稱」→ 按進入房間 → 確認隊友與模式後按下「開始拆彈」。
  3. 每過一關自動輪流職位：不分人、不綁定角色，隊友輪流扮演 💣 拆彈手 與 📖 指揮官！

🔄 兩個職位怎麼配合？

  • 💣 拆彈手：看得到炸彈外殼資料（電池數、序號、指示燈）與關卡內容！負責唸資料給指揮官、拼出 Scratch 積木或操作動作小遊戲。
  • 📖 指揮官：看不到炸彈畫面！依照拆彈手報的資料點選篩選問題，立刻找到唯一正確的 Python 規則、迷宮地圖或摩斯表，口頭指揮拆彈手。

⚠️ Scratch vs Python 最常見 3 大陷阱

  1. Scratch 沒有 elif：要用兩層「如果...那麼...否則」包在否則裡面。
  2. 清單索引差 1：Python wires[0] 是 Scratch 的 第 (1) 項，wires[-1] 是 第 (清單長度) 項。
  3. while 與 重複直到 條件相反：Python while temp > 30 在 Scratch 要寫 重複直到 temp ≤ 30！
