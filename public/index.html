  • 🕶️ 國二指揮官（1 人）：坐在看不到國一螢幕的地方！手上有「Python 拆彈手冊」、「小遊戲手冊（大按鈕/迷宮圖/摩斯表）」和「PY↔Scratch 對照表」，完全看不到炸彈本身！
  • 🧩 國一雙人搭檔（2 人坐旁邊！）：沒有聾人/盲人限制，兩人並肩討論超順暢：
    • 並排用 2 台電腦：🔭 偵察員管炸彈外殼、程式安全插銷，並親手玩「大按鈕 / 雷射迷宮 / 摩斯電台」；🧩 程式師主攻「Scratch 積木程式」＋幫搭檔盯閃燈/算秒數！
    • 共用 1 台電腦：選「🛠️ 國一雙人共用機」，每解完一個關卡自動提醒「偵察手 ⇄ 主控手」交換滑鼠，保證大家都很忙！

🕹️ 遊戲關卡兩大類型

  • 🧩 Scratch × Python 程式模組（6 種）：國二看 Python 規則與 PY 對照表口頭指導，國一拼出 Scratch 積木並通過多組驗證。
  • 🔥 非程式動作小遊戲（3 種）：
    • 🔴 終極香蕉大按鈕：依據電池與指示燈決定「快點一下」或「按住不放等光條亮起＋倒數秒數出現指定數字放開」！
    • 🧭 隱藏雷射迷宮：國一看定位環座標，國二看完整牆壁地圖即時指揮走位（可用鍵盤方向鍵 / WASD）。
    • 📻 摩斯香蕉電台：國一看信號燈長短閃爍報給國二，國二查出單字後告訴國一調到幾 MHz 發射！

⚠️ 經典 Scratch vs Python 陷阱提醒

  1. Scratch 沒有 elif：要用兩層「如果...那麼...否則」巢狀包起來。
  2. 清單索引差 1：Python wires[0] 在 Scratch 是 第 (1) 項！
  3. while 與 重複直到 條件相反：Python while temp > 30 在 Scratch 要寫 重複直到 temp ≤ 30！
